# Meeting Recorder (PWA)

React + TypeScript + Vite + Tailwind + shadcn-style UI + PWA.

## Prerequisites

- Node 18+ and npm (or pnpm/yarn)

## Setup

```bash
npm install
```

## Develop

```bash
npm run dev
```

Open http://localhost:5173. The page shows "Meeting Recorder" and a button; Tailwind and the Button component are in use.

## Build

```bash
npm run build
```

Output in `dist/`. Preview with `npm run preview`.

## PWA

- Service worker and web app manifest are generated by `vite-plugin-pwa` (see `vite.config.ts`).
- Add `public/icon-192.png` and `public/icon-512.png` for install icons, or remove the `icons` array from the manifest in `vite.config.ts`.
- In the browser, Application tab → Service Workers / Manifest to verify.

## API

Set `VITE_API_BASE` to the backend base URL (no trailing slash). Example:

```bash
VITE_API_BASE=http://localhost:8000 npm run dev
```

Default: same origin (empty string).
